Good pratices for revit family creation

  • Use reference planes to constrain the geomentry
  • Model the only the parts which will be visible in the 3d view
  • Use standarised naming conventions
  • Limit the use of nested families, arrays, voids and maintain parameters that will be actively used
  • Plan the process
  • Prefer family instance instead of modelling the same geometry again or using groups
  • check the family in the project environment

Family Parameter types

  • We have two types of parameters they are generic family parameters and Shared Parameters Both of these can be further classified as Type and Instance parameter.
  • We use Shared parameter to parameters that are need to be scheduled, like Cost, Equipment Code, etc. For other cases use generic family parameters.
  • Whenever we create a new family it comes with certain parameters that we cannot delete and are called built-in parameters.
  • Built-in parameters are also a kind of generic family parameters.
  • We can change the category of the family even in the middle of family creation ie from generic to furniture category.
  • Use the right type of family template while creating the family ie, wall or ceiling hosted or level based family we can’t change the family type ex, from level based family to wall hosted family is not possible.
