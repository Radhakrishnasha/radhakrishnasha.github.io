Split column at levels

This Dynamo script automates the process of splitting existing Structural Columns in a Revit model at multi-story building levels. It identifies existing columns, generates intersection planes based on building story elevations, intersects the columns with these planes, deletes the original columns, and recreates new segmented structural columns using curves and specified column types.


1. Selection & Location of Existing Columns (Top Branch) Categories & All Elements of Category: Selects the "Structural Columns" category and retrieves all column instances currently in the Revit model.
Elements.Delete & Element.GetActualLocation: Retrieves the actual spatial geometry/location of the structural columns and flags the original elements for deletion once the new split columns are generated.
2. Level Filtering & Elevation Extraction (Bottom-Left Branch) Categories & All Elements of Category (Levels): Pulls all "Levels" from the Revit model. Element.GetParameterValueByName & List.FilterByBoolMask: Evaluates the **"Building Story"** parameter to filter and keep only the relevant building story levels.
Element.GetParameterValueByName (Elevation) & Math.Round: Extracts the elevation values of the filtered levels and rounds them to get precise vertical heights.
3. Plane Generation & Geometry Intersection (Middle Section) Plane.XY & Plane.Offset: Creates a base horizontal reference plane and offsets it vertically using the rounded level elevation values.
Geometry.Intersect & List.OfRepeatedItem: Intersects the column geometries with the offset building story planes to find the exact splitting points or curves along the height of each column.
4. Data Processing via Python (Right-Middle Section) List.NormalizeDepth: Adjusts and organizes list structures to ensure data consistency after the intersection operation.
Python Script: Processes the intersection outputs and curves to structure them properly for column recreation.
5. Recreating Split Columns (Far Right) List.FirstItem & Structural Column Types: Gathers the required reference levels and selects a specific structural column type (e.g., "300 x 450mm") from the model.
StructuralFraming.ColumnByCurve: Takes the processed curves, levels, and column types to generate and place the new, split structural columns back into the Revit model.
