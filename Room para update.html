Room finish updater

This Dynamo script automates the process of generating or updating floor and ceiling finishes in Autodesk Revit rooms. Instead of manually modeling floor and ceiling elements for every room, the script reads room data (such as boundary shapes and finish specifications), extracts the necessary curves and parameters, and automatically creates the corresponding finish elements within the Revit model.


1. Collecting Room Elements (Left Side) Category and Selection: The script starts on the far left by targeting the "Rooms" category to gather all room elements present in the Revit project.
Data Retrieval: Nodes process the selected rooms to prepare them for boundary and parameter extraction.
2. Extracting Finish Parameters & Properties Reading Specifications: The script queries specific room parameters (such as designated floor finish or ceiling finish types) using parameter getter nodes. Level Mapping: It also pulls level data to ensure the newly created finish elements are placed at the correct elevations.
3. Processing Room Boundaries Boundary Geometry: The script extracts the spatial boundaries of each room to generate closed loop curves.
Curve Management: These curves serve as the precise footprints/outlines required to model the individual floor and ceiling finish layers.
4. Creating Floor and Ceiling Elements Element Generation: Using creation nodes (such as those for floors and ceilings), the script takes the extracted boundary curves, floor/ceiling types, and level information to physically build the finish elements inside the rooms.
5. Finalizing and Setting Parameters (Right Side) Parameter Assignment: The nodes on the right-hand side apply final properties, set parameter values, or link the newly created finishes back to the respective rooms for scheduling and documentation.
