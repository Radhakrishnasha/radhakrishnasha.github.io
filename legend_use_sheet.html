Check for legend usage in sheet

This Dynamo script automates the process of checking whether a specific view or legend is placed on any sheets within a Autodesk Revit model.By querying all sheets and comparing their placed views against a user-selected target view, the script identifies and reports which sheets contain that specific legend or view.


1. Gathering Inputs (Left Side). Collecting All Sheets: The top-left branch uses a `Categories` node set to "Sheets" coupled with `All Elements of Category` to retrieve every sheet present in the Revit project.
Selecting the Target View/Legend: The bottom-left selection node allows the user to select the specific view or legend they want to check. A `Viewport.View` node extracts the underlying view data from this selection.
2. Extracting Sheet Contents. The `Sheet.Views` node analyzes the collected sheets and extracts a list of all views (floor plans, details, legends, etc.) placed on each individual sheet. `String from Object` nodes convert element data into text strings to prepare them for comparison and filtering.
3. Comparing and Filtering Data. Boolean Evaluation: Nodes like `List.AnyTrue`, `List.FilterByBoolMask`, and conditional checks compare the target view against the views found on each sheet. This filters the list to isolate only the sheets that contain the specified legend or view.
4. Logic Processing and Python Scripting. A Python Script node handles complex list management, checking whether the resulting filtered list contains items or is empty (`List.IsEmpty`). Code blocks extract parameters such as sheet numbers and view names (`Element.GetParameterValueByName`) to structure the data properly.
5. Formatting and Reporting (Right Side) `String.Join` and `List.Flatten` nodes combine the matching sheet data into a clean, readable format.
The final conditional nodes (`If`) and notification/watch nodes evaluate the final count and display a summary or message indicating whether (and where) the legend is being used on sheets.
