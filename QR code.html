QR code from element data

This Dynamo script automates the process of extracting element data (specifically "Furniture" element IDs) from a Revit model, using a Python script to generate a custom "QR code" image representing that data, saving it to a designated folder directory, and finally reading and previewing the generated QR code image directly within Dynamo.


1. Element Data Extraction (Bottom Branch) Categories & All Elements of Category: The script starts by selecting the **"Furniture"** category and pulling all furniture instances present in the Revit project.
Element.Id: Extracts the unique element IDs for each of the selected furniture items to serve as the data payload for the QR code.
2. Directory Path Configuration (Top Branch) Directory Path & String from Object: The user specifies a target folder path on their computer (e.g., on the Desktop inside a `dynamo` folder) where the generated QR code image file will be saved. This path is converted into a string format so it can be read by the script.
3. QR Code Generation (Middle Section) Python Script: This node takes the directory path (`IN[0]`) and the element IDs/data (`IN[1]`) as inputs. It executes custom Python code to encode the data into a QR code graphic and saves it as a `.png` file (such as `1245858.png`) in the specified folder.
4. Image Loading and Preview (Right Section) File From Path:** Takes the file path of the newly generated QR code image.
Image.ReadFromFile: Loads the saved image file into Dynamo as a bitmap object (`System.Drawing.Bitmap`).
Watch Image: Displays a visual preview of the generated QR code directly in the Dynamo workspace.
